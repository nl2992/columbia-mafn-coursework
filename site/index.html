THE COURSE LIBRARY

About this edition

A static build of the archive's local research app, hosted on GitHub Pages.

How it works

  • Library searches a prebuilt index of every extracted page, slide, cell range and code block. Search runs in your browser, loading only the index pieces a query needs.
  • Copilot searches every course for passages that match your question (solutions and exams excluded). It then asks Qwen3 30B, running on Cloudflare Workers AI, to answer from those passages alone. Only your question and the passages are sent, and nothing is stored. A claim is kept only if its quotation appears word for word in the cited passage, and if nothing survives, it declines to answer. If the service is unavailable, you can answer on your own device instead, after a one-time 2.3 GB download.
  • Data opens the original workbook with SheetJS and runs the operation you choose on the exact range you give.

Differences from the Mac app

  • Search is keyword-based. The Mac app also uses MiniLM semantic similarity, so it finds more paraphrases.
  • The Copilot service has a free allowance of about 300 questions a day. After that, answering on your own device needs a browser with WebGPU (current Chrome, Edge, or Safari).
  • Conversations and saved passages aren't stored. Search and Data never leave your browser.
  • ZIP archives and a few very large files open from GitHub instead of from this site.

For semantic search, saved research, and adding documents, run the full app on a Mac or in GitHub Codespaces.
