## Working with the materials

- PDFs contain lecture notes, syllabi, exams, problem sets, and research references.
- Excel workbooks include `.xls`, `.xlsx`, and `.xlsm` files. Macro-enabled workbooks should only be opened with macros enabled when the source is trusted.
- MATLAB examples are stored beside the relevant course materials and are documented in the course README.
- Python and Jupyter materials are concentrated in the Numerical Methods course, especially `HW3` and `HW4`.
- Large datasets and binary files are configured for Git LFS; see [REPOSITORY_GUIDE.md](REPOSITORY_GUIDE.md).
- Local textbook matches are cataloged in [TEXTBOOK_CATALOG.md](TEXTBOOK_CATALOG.md), with course associations and rights-aware handling notes.

## Archive boundaries

This is a Canvas **Files** export, not a complete course reconstruction. Materials that existed only inside Modules, Assignments, Announcements, Pages, Ed, Slack, email, or external systems may not be present. The original inventory is preserved in [INDEX.md](INDEX.md).
