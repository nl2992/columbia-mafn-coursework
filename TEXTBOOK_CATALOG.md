## Integration policy

Several source filenames explicitly include `Anna’s Archive`. Full textbooks are copyrighted works, and a private GitHub repository is still an external distribution service. For that reason, this pass integrates bibliographic metadata and course associations but does not copy the full-book binaries into the Canvas archive or project repositories.

If you have a licensed copy or explicit redistribution permission for a specific title, it can be added later under a course repository’s `references/textbooks/` directory after a rights review. Otherwise, acquire or link to the title through the publisher, library, or another authorized source.
