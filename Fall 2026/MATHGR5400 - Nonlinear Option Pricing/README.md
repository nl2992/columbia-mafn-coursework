# MATHGR5400 — Nonlinear Option Pricing

**Term:** Fall 2026  
**Archive type:** CourseWorks files

## Overview

Taught by Julien Guyon and Bryan Liang. The course covers the nonlinear PDEs that arise in practice — American option pricing, uncertain volatility and mortality, different borrowing and lending rates, smile calibration, CVA, transaction costs, illiquid markets, and super-replication under delta and gamma constraints. Theory includes optimal stopping, stochastic control, BSDEs, McKean SDEs and the particle method, and branching diffusions. The emphasis is on simulation-based (Monte Carlo) methods and machine-learning regression, with Python notebooks using PyTorch and TensorFlow.
