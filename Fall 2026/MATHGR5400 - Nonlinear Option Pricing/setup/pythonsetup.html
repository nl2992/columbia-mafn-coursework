Set Up Your Scientific Python Computing Environment

In this course, you are expected to use the Python programming language for the computing assignments and return your work in the form of a Jupyter notebook.

The main goal of this note is to get you started with setting up the Python computing environment.

I recommend that you install the necessary software on your personal computer. The easiest way to get started with the Python scientific stack is to install the Anaconda Python distribution. It is freely available for download at the URL https://www.anaconda.com/download. You are encouraged to download the latest version of Python 3 (3.13, earlier versions may also work). This should work on Windows, Mac and Linux. As soon as you are finished with the installation, you can start using the Jupyter notebook simply by typing "jupyter notebook" or "jupyter lab" in the console. The Windows and Mac versions also come with a graphical launcher.

In combination with packages like numpy, scipy, and matplotlib, Python provides an environment that is similar to domain specific programming languages like R or Matlab. Numpy is the fundamental package for scientific computing with Python. It provides support for large multi-dimensional arrays and matrices along with basic numerical routines; SciPy contains additional numerical routines such as numerical integration, interpolation and optimization. Matplotlib is a popular graphing and data visualization package for Python. Other libraries of interest include pandas, a data analysis library, scikit-learn, a machine learning library. For deep learning libraries, we recommend PyTorch or TensorFlow. All these packages except TensorFlow and PyTorch come bundled with Anaconda.

You may use CPU-only PyTorch or TensorFlow for the homework assignments. The GPU support is optional.
