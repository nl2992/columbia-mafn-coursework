# IEOR4735 — Continuous Time Finance

**Term:** Fall 2026  
**Archive type:** CourseWorks files

## Overview

Continuous-time arbitrage theory following Tomas Björk's *Arbitrage Theory in Continuous Time* — stochastic integrals, Black–Scholes, martingale pricing, dividends, currency derivatives, change of numeraire, incomplete markets, short-rate and forward-rate models, and stochastic control — together with stochastic-volatility modelling based on Lorenzo Bergomi's *Stochastic Volatility Modeling*, SVI parameterization, and LSV calibration.
