# MATHGR5380 — Multi-Asset Portfolio Management

**Term:** Spring 2026  
**Archive type:** Canvas Files export  
**Original files:** 82

## Course focus

The archive covers the design, analysis, and implementation of multi-asset portfolios. Core themes include return statistics, Bayesian investing, Black–Litterman, factor and risk models, strategic asset allocation, performance attribution, transaction costs, regime shifts, momentum, carry, and portfolio optimization.
