# MATHGR5030 option models

Small Python package scaffold used by the SABR homework.

| File | Role |
| --- | --- |
| [`__init__.py`](__init__.py) | Package initializer |
| [`sabr.py`](sabr.py) | Base model abstraction plus standard and conditional Monte Carlo SABR classes |

Observed dependencies in `sabr.py` are `numpy`, `pyfeng`, and the Python standard library. The model methods include explicit instructional placeholders and should be completed and tested in the context of the accompanying notebook.
